# Lost & Found Mobile App

A mobile application designed to help users report and find lost or found items, making it easier to reunite them with their rightful owners through smart matching and community collaboration.

## 📱 Overview

The Lost & Found Mobile App provides a centralized platform where users can:
- Report lost or found items with detailed descriptions and photos
- Browse and search through reported items
- Receive notifications when potential matches are found
- Share posts to increase visibility and improve chances of recovery

## 👥 Main Actors

### User
- Reports lost or found items
- Browses the list of reported items
- Receives notifications when a matching item is found
- Shares posts about lost or found items

### Administrator
- Moderates posts to detect spam using anomaly detection
- Manages user accounts, including banning abusive users
- Accesses the dashboard for system overview and analytics

## ✨ Key Features

### Item Management (Lost & Found)

#### Reporting an Item
- **Simple Form Interface**: Users fill out forms with item description, photo, and location
- **AI-Powered Post Generation**: Option to have posts automatically generated by AI based on provided descriptions
- **Categorized Posts**: Separate sections for lost and found items ensuring clarity and easy matching
- **Photo Upload**: Visual identification through image uploads

#### Searching for an Item
- **Advanced Filtering**: Search by category, location, date, and color
- **Relevance-Based Sorting**: Results sorted by relevance to improve matching accuracy
- **Smart Notifications**: Automatic alerts when similar items are reported

### User Management

#### Authentication
- **Traditional Login**: Standard email/password authentication
- **Social Media Integration**: OAuth authentication via popular social platforms
- **Secure Registration**: User account creation with verification

#### User Dashboard
- **Personal History**: View past lost and found item reports
- **Account Management**: Manage profile settings and preferences
- **Activity Tracking**: Monitor post performance and interactions

### Interactive Map
- **Location Visualization**: Displays precise locations where items were reported lost or found
- **Geographic Clustering**: Visual representation of item concentration areas
- **Location-Based Search**: Find items within specific geographic areas

### Communication 
- **Integrated Messaging**: Direct communication system between users who have lost or found items

## 🤖 AI Integration

### Smart Matching System
- **Text Analysis**: AI compares descriptions of lost and found items for potential matches
- **Image Recognition**: Computer vision technology identifies similar objects in uploaded photos
- **Automatic Suggestions**: AI generates relevant post recommendations based on item characteristics
- **Match Scoring**: Intelligent ranking of potential matches based on multiple factors

## 🚀 Technology Stack

- **Mobile Development**: Flutter
- **Backend & Database**: Firebase (Firestore, Authentication, Storage, Functions)
- **Authentication**: Firebase Auth with OAuth integration
- **Maps Integration**: Geographic mapping services
- **Push Notifications**: Firebase Cloud Messaging (FCM)

## 🎯 Target Users

- **General Public**: Anyone who has lost or found personal items
- **Students**: University and school communities with high item turnover
- **Travelers**: Airport, hotel, and transportation hub users
- **Event Attendees**: Conference, concert, and public event participants
- **Community Members**: Local neighborhoods and community organizations

### Prerequisites
- Flutter SDK (latest stable version)
- Dart SDK
- Android Studio / VS Code with Flutter extensions
- Firebase account and project setup

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dhia9030/FoundIt.git
   cd FoundIt
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Firebase Setup**
   - Create a new Firebase project at [Firebase Console](https://console.firebase.google.com)
   - Enable Authentication, Firestore Database, and Storage
   - Download `google-services.json` (Android) and `GoogleService-Info.plist` (iOS)
   - Place the configuration files in their respective platform directories

4. **Run the app**
   ```bash
   flutter run
   ```

### Firebase Configuration
Make sure to enable the following Firebase services:
- **Authentication**: Email/Password and OAuth providers
- **Firestore Database**: For storing item reports and user data
- **Storage**: For uploading item photos
- **Cloud Functions**: For AI matching and notifications

Development Commands
```bash
flutter run  //Run the app in debug mode
flutter build apk  //Build APK for Android
flutter build ios  //Build for iOS
flutter test  //Run unit tests
```
